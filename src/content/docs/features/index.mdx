Recipery is a self-hosted recipe manager: add recipes by hand or import
them from a URL, organize them into collections, cook them full-screen
with Cook Mode, and keep track of what you and anyone else on the
install has cooked — all backed by object storage, with no database
underneath it.

<CardGrid>
  <Card title="Library & Recipes" icon="ph:cooking-pot">
    Add recipes by hand or import them, scale servings, filter and rate
    what you cook, and see who else cooked it. See [Library & Recipes](/features/library).
  </Card>
  <Card title="Collections" icon="ph:stack">
    Group recipes into collections — five to start, and as many more as
    you want. See [Collections](/features/collections).
  </Card>
  <Card title="Profiles & Access" icon="ph:users">
    Multiple cooks per install, admin/reader roles, optional per-profile
    passwords. See [Profiles & Access](/features/profiles).
  </Card>
  <Card title="Shopping List" icon="ph:shopping-cart">
    Add recipes to one consolidated, checkable ingredient list — quantities
    from different recipes merge automatically where it's safe to. See
    [Shopping List](/features/shopping-list).
  </Card>
  <Card title="Import from a URL" icon="ph:link">
    Paste a link and Recipery scrapes the title, ingredients, steps, and
    photo straight from the page — or paste a YouTube link to pull in
    the video too. See [Import from a URL](/features/import).
  </Card>
</CardGrid>
